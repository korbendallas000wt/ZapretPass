
# ZapretPass

Графический менеджер для [zapret](https://github.com/bol-van/zapret) — инструмента обхода DPI-блокировок.

Позволяет подбирать рабочие стратегии обхода для заблокированных сайтов, искать универсальные стратегии для групп доменов и управлять сервисом через удобный интерфейс.

---

## Возможности

### Уже реализовано (ядро)
- Управление systemd-сервисом zapret (старт/стоп/рестарт, статус)
- Определение текущего режима работы (whitelist / global)
- Запуск blockcheck.sh с интерактивными ответами и парсинг найденных стратегий
- Поиск универсальных стратегий через пересечение и объединение результатов
- Применение стратегий и режимов к конфигу запрута с автоматическим бэкапом
- Перехват SNI-доменов через tshark
- Проверка доступности сайтов через curl с классификацией вердиктов
- Управление whitelist доменов
- Именованные пресеты стратегий
- Кэширование пароля sudo с проверкой валидности

### В разработке
- Qt6-интерфейс с вкладками для управления всеми функциями
- Установщик движка zapret (самодостаточная установка)
- Fast-режим блокчека (остановка на первой рабочей стратегии)
- Двухфазный поиск вспомогательных доменов
- Предзагруженные списки вспомогательных доменов для популярных сайтов

---

## Архитектура

Приложение разделено на два слоя:

1. **core/** — ядро, бизнес-логика без привязки к UI. Ни один модуль не импортирует Qt.
2. **ui/** — графический интерфейс на Qt6 (в разработке).

Это позволяет:
- Тестировать логику отдельно через Python-скрипты
- Менять интерфейс без переписывания ядра
- Использовать ядро из командной строки

Подробнее о модулях — в [PROJECT_MANIFEST.md](docs/PROJECT_MANIFEST.md).

---

## Требования

- **ОС:** Linux с systemd (протестировано на Manjaro)
- **Python:** 3.10+ (для Qt6)
- **Системные пакеты:**
  - `zapret` — движок обхода DPI
  - `wireshark-cli` (tshark) — перехват сетевых пакетов
  - `curl` — проверка доступности сайтов
  - `kdialog` (KDE) — графический диалог запроса пароля
- **Привилегии:** sudo или pkexec для управления сервисом и конфигом

## Установка

> ⚠️ Установщик пока в разработке. Ниже — ручная установка.

1. Установите zapret по [инструкции](https://github.com/bol-van/zapret/blob/master/docs/quick_start.md)
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/korbendallas000wt/ZapretPass.git
   cd ZapretPass
   ```
3. Переключитесь на ветку разработки:
   ```bash
   git checkout dev
   ```
4. Запустите (после появления UI):
   ```bash
   python3 main.py
   ```

## Использование (после релиза UI)

1. Запустить приложение
2. При первом запуске — установить движок zapret (или указать существующий)
3. Ввести пароль sudo при первом привилегированном действии
4. Использовать вкладки:
   - **Сервис** — управление запрутом
   - **Стратегии** — пресеты, выбор, применение
   - **Поиск** — блокчек для конкретного домена
   - **Whitelist** — редактирование белого списка
   - **Сниффер** — перехват вспомогательных доменов
   - **Проверка** — диагностика доступности сайтов
