## Сессия 2026-10-03 — Этап 2: сохранение состояния и честная диагностика
**Сделано:**
- Добавлен `core/passport.py` с `PassportManager` для атомарной записи паспортов сайтов.
- Внедрена папочная структура `data/sites/{domain}/` (вместо плоского JSON).
- Блок диагностики записывает результат проверки в `passport.json`.
- Блок блокчека временно записывает основную найденную стратегию в паспорт.
- Добавлена защита от мусорных паспортов:
  - DNS-ошибка теперь классифицируется как вердикт `not_found` (вместо `blocked`).
  - Паспорт создаётся/обновляется только при вердикте `blocked`.
  - Для несуществующих доменов паспорт не создаётся, а сервис не останавливается.
- Диагностика стала честной:
  - Сначала проверяется резолв домена через `socket.getaddrinfo` без запроса sudo.
  - Затем запрашивается пароль, сервис останавливается.
  - Выполняется проверка доступности без обхода DPI.
  - Сервис гарантированно перезапускается после завершения диагностики (даже при ошибке).
- Добавлен безопасный cleanup для блокчека:
  - Сохранение `flags` и `password` в контексте UI при старте блока.
  - Гарантированный вызов `cleanup_after_block()` на `finish`, `error` и при остановке пользователем.
  - Устранён риск остаться с остановленным сервисом после сбоя или отмены блокчека.
- `ServiceManager` больше не перезаписывает `_service_was_active` внутри одного блока (добавлен `_context_initialized`).
- `cleanup_after_block()` теперь автоматически вызывает `reset_context()` после завершения блока.

**Коммиты:**
- `a686c6b` core: добавлен PassportManager для сохранения состояния сценариев
- `54b1265` checker: добавлена защита от опечаток (вердикт not_found)
- `5b246a7` ui: честная диагностика и безопасный cleanup сервисных блоков

**Технический долг / Заметки:**
- Между диагностикой и блокчеком сейчас происходит двойной stop/start сервиса. Это безопасно для текущего "Уровня 1", но в будущем должно оптимизироваться полноценным workflow-движком.
- В паспорте пока сохраняется техническое поле `mode` как `"1"` и `duration: 0`. Для финального UI паспорта это не приоритетно, позже будет скрыто или нормализовано.
- Финальный виджет паспорта (4 зоны: скрин, заголовок, диагностика, стратегия) пока не реализован, запланирован как следующий шаг.

**Следующие шаги:**
- Проектирование и реализация каркаса финального виджета паспорта (последний блок сценария).
- Интеграция остальных блоков (sniffer, browser, apply, save) с PassportManager.

## Сессия 2026-10-04 — Детерминированные ID стратегий и schema_version

### Что сделано

#### 1. Детерминированные идентификаторы стратегий
Проблема: длинные команды `nfqws --dpi-desync=...` нечитаемы, а порядковая нумерация не работает при обмене паспортами.

Решение:
- Создан `StrategyParser` в `core/passport.py`
- Формат ID: `<type>/ttl=<ttl>/<hash4>` (например, `fake/ttl=4/1576`)
- Алиас: `<type>/ttl=<ttl>` (например, `fake/ttl=4`)
- ID детерминированный: одна стратегия у разных пользователей получит один ID

#### 2. Schema version и provider
Добавлены в модель `Passport`:
- `schema_version: int = 1` — версия схемы паспорта
- `provider: str = ""` — провайдер (пока пустой, для будущего автоопределения)

#### 3. Новый формат стратегий
Старый формат:
```json
{"strategy": "nfqws --dpi-desync=...", "found_at": "..."}
```

Новый формат:
```json
{
  "id": "fake/ttl=4/1576",
  "alias": "fake/ttl=4",
  "command": "nfqws --dpi-desync=...",
  "found_at": "..."
}
```

#### 4. Обновлённые методы
- `set_primary_strategy()` — сохраняет `id`, `alias`, `command`
- `add_strategy()` — генерирует ID/алиас при добавлении
- `_migrate_legacy_strategies()` — генерирует ID при миграции старых данных
- `mark_auxiliary_strategy()` — сохраняет `strategy_id`, `strategy_alias`, `strategy_command`

#### 5. Миграция данных
- `data/sites/youtube.com/passport.json` обновлён на новый формат
- Добавлены `schema_version: 1` и `provider: ""`

#### 6. Обновление UI
- `ui/passport_view.py` показывает алиас стратегии вместо полной команды
- Полная команда доступна в tooltip
- Вспомогательные домены показывают `strategy_alias`

- `ui/passport_view.py` — чтение нового формата, отображение алиасов
